## What changed in the repository

- The development kit adopted (#31) and its scripts re-vendored through v0.2.0, v0.4.0, v0.5.0, v0.8.0, v0.9.0 and v0.10.0 (#32, #35, #36, #40, #42, #43), with the branch-update workflow (#36).
- A pull request runs the checks its changed paths map to (`jpdev.json`, #41); a push to `main` and a manual dispatch run the whole list.
- The release workflow reuses `main`'s exact-commit CI evidence for the history-independent checks and keeps the native checks that need the tag (#44): the evidence must come from a trusted branch and event, name the same workflow, jobs and toolchain, and record the commit's input identities; otherwise the release refuses. This is the gate's first live use on this repository.
- GitHub Actions are pinned by digest at the versions the tagged commit's workflows name.
